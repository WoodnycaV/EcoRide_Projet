# EcoRide_Projet

## Mise en place de l’environnement de travail

### Outils de développement

**Visual Studio Code** : Éditeur de code (extensions pour HTML, CSS, JavaScript et PHP).

**XAMPP** : permet de travailler dans un environnement de développement local (Apache, PHP, MySQL).

**phpMyAdmin** : permet la gestion de base de données via une interface graphique.

**Google Chrome / Firefox** : pour tester le rendu et utiliser les outils de développement intégrés 
(inspection).


J'ai utilisé ces outils car ils sont gratuits, accessibles, bien documentés et adaptés à ce projet en PHP/MySQL.
